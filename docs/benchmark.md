# 作者基准记录（2026-10-26，历史摘要）

以下为原实现作者提交的记录。示例表单现已泛化为名称、测试编号、类别及数量，历史耗时未针对当前表单重新测量。原始事件日志和完整测量材料未随仓库交付。本次公开发布审查没有独立重跑这些性能数据，不能将它们当作当前修订的性能验收或其他机器的保证。新增修正以仓库中的离线回归为证据，真实客户端和业务流程仍需验证。

环境：Apple Silicon Mac，macOS 27，Xcode 27.0，iOS 27.0 模拟器（专门新建的测试机，测完删除），Node 25，serve-sim 0.1.48。所有操作都在本地测试页和系统“设置”App 上进行，没有真实业务、网络提交或账号。

## 1. 单次操作耗时（工具层，不含模型）

每项连测 3 次，单位秒。

| 操作 | serve-sim 常驻连接（本技能） | serve-sim CLI（每次新进程） | AXe 1.8.0 | IDB 1.1.8 |
|---|---|---|---|---|
| 读界面 | 0.59–0.63（`/ax`） | — | 0.64–0.90 | 0.32–0.35 |
| 点击 | 0.052 | 0.69–1.55 | 0.79–0.87 | **失败**：Xcode 27 下 SimulatorKit 加载报错 |

结论：点击用常驻连接；读界面 IDB 更快，但它不能点击，再引入一个后台进程只省约 0.3 秒/次，所以不采用。

## 4. 安全规则（作者报告的模拟器验证）

| 检查 | 结果 |
|---|---|
| 运行中暂停 | 第 1 步后暂停，`status=paused`、`stopped_before=1`，退出码 5；暂停期间再次运行一步都不执行 |
| 失败即停 | 预期没出现时停在出错步骤，后续步骤没执行，没有自动重试 |
| 提交结果未知 | `status=unknown`，退出码 3；serve-sim 事件日志确认只有 1 次点击 |
| 占用冲突 | 其他 owner `start`/`run` 被拒绝，退出码 4 |
| 释放 | 自己启动的 helper：停止并核实进程已退出；别人启动的 helper：复用，释放时保留 |
| 前台 App 不符 | 一步都不执行 |
| Xcode 27 文字输入 | 首次无效（Device Hub 遮挡）；`repair-input` 后输入正常 |

原实现当时单元测试 `npm test`：12 项（假设备，覆盖上述规则、计划校验和复审发现的问题）。

## 4.1 作者早期复审修正（原记录声称复验，非本次复验）

| 问题 | 修正 | 复验 |
|---|---|---|
| 条件写错键名或为空时被当作已满足，提交步骤报 ok | 条件必须指向具体元素，未知键拒绝 | 单元测试；模拟器退出码 2 |
| 提交发出后连接或读取出错报 failed | 一律报 unknown | 单元测试 |
| helper 换成别的进程后，`stop` 会关掉它 | 只关闭 pid 与登记一致的 helper | 模拟器：别人的 helper 保留 |
| `--udid` 可路径穿越，`resume` 能删任意文件 | 校验 UDID 格式 | 模拟器：拒绝，文件未删 |
| `stop` 会清除用户的暂停 | 暂停只由用户解除 | 模拟器：释放后暂停仍在 |
| 两个 owner 同时 `start` 可能都拿到占用 | 原子创建占用文件 | 代码审查 |
| 回车提交可以不写等待条件 | `key` 也必须写 `expect` | 单元测试 |
| 计划读取失败的退出码与文档不符 | 统一为 2 | 模拟器 |

## 5. 这些数字不能说明什么

- 只各跑了一条示例路线；基线各只跑 1 次，优化后模拟器跑 5 次、浏览器 1 次。不是统计意义上的提速比例。
- 浏览器只测了 Claude 内置浏览器；Codex 内置浏览器没有做计时对比。
- 没有在自定义 App、App 内 WebView/H5、需要登录或权限弹窗的页面上测过。
- 没有覆盖跨会话交接、等待用户等时间；只含单个会话里的模型往返。
- “别人启动的镜像”是用 serve-sim CLI 模拟的，不是 Codex 预览服务器本身。
- 只在 Xcode 27 / Apple Silicon 上测过。
